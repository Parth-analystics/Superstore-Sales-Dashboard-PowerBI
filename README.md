# 📊 Superstore Sales Dashboard | Power BI

## 📌 About the Project

The **Superstore Sales Dashboard** is an interactive data visualization project developed using Microsoft Power BI to analyze two years of sales data.

The dashboard provides insights into sales performance, profitability, customer segments, product categories, shipping modes, and regional trends through interactive charts, graphs, maps, and KPI cards. It also includes a weather forecasting feature.

## ✨ Key Features

* 📈 **Sales Analysis:** Analyze sales and profit trends over two years.
* 📊 **Interactive Visualizations:** Explore data through multiple charts and graphs.
* 🌍 **Geographical Analysis:** Visualize regional sales using maps.
* 🎯 **KPI Cards:** Monitor key metrics such as total sales, orders, and profit.
* 🛍️ **Category Analysis:** Compare sales across product categories and subcategories.
* 🌦️ **Weather Forecasting:** Additional weather forecasting feature.
* 🔍 **Interactive Filtering:** Explore data using filters and visual interactions.

## 🛠️ Tools & Technologies

* Microsoft Power BI
* Microsoft Excel
* Data Visualization
* Data Analysis

## 🎯 Project Objective

The objective of this project is to transform raw sales data into an interactive dashboard that makes business performance easier to understand and helps users explore trends, patterns, and insights.
